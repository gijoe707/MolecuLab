# 🧬 MolecuLab — Interactive Molecular Structure Builder

**MolecuLab** is a sophisticated browser-based educational application designed for the **interactive construction and visualization of molecular structures**.  

Built with modern web aesthetics and high-performance rendering, MolecuLab allows users to assemble molecules on a dynamic **2D simulation canvas** and validate them against **real-world chemical rules**.

---

# 🚀 Key Features

### 🧪 Dynamic 2D Simulation Canvas
A custom-built **HTML5 Canvas engine** supporting:

- High-performance atom placement  
- Multi-order bonding  
- Smooth drag-and-drop manipulation  

---

### 📚 Progressive Learning Modules
Includes **5 structured learning modules (20 molecules total)**:

- Inorganic Basics  
- Organic Fundamentals  
- Functional Groups  
- Advanced Organic Structures  
- Experimental Molecules  

---

### ⚡ Real-time Validation Engine
An **Auto-check system** that instantly verifies structures against:

- Molecular formulas
- Chemical bonding rules
- Molecular geometry  

Examples:

- Bent geometry of `H2O`
- Triple bond in `N2`

---

| Element | Symbol |

# 📖 How to Build Molecules

### 1️⃣ Place Atoms
Select an element from the **Atom Palette** and click anywhere on the canvas.

---

### 2️⃣ Create Bonds
Enter **Bond Mode**:

1. Click a source atom  
2. Click a target atom  

A bond will be created between them.

---

### 3️⃣ Adjust Structure
- Drag atoms to reposition them
- Bonds update dynamically in real-time

---

### 4️⃣ Verify Structure

Use:

- **Check Button** – manual validation  
- **Auto-validate Toast** – real-time structure verification
